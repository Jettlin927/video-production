# 生成画面风格预设

在锁定 `visual_style` 前读取。这里给出 5 套可直接使用的预设，供 Agent 按**该片的文案内容**和**片子质感**自选，不要每次即兴写一套风格。

## 选择流程

1. **先看文案在讲什么**——按下面「选型表」定位候选。
2. **再看片子质感**——真人实拍口播、纯排版动画、还是混剪？生成画面要和它同处一个世界：实拍口播配写实，纯排版配科技/界面。
3. **定一套，整片一致**。`visual_plan.py` 要求每个生成镜头的 `style_id` 等于计划里的 `visual_style.id`：**一条片子只用一套预设**。不要在同一片里混风格。
4. **画幅跟随成片**：竖屏成片（9:16）出竖幅，横屏成片（16:9）出横幅，把结论写进 `composition`。不要把横屏素材硬塞进竖屏全屏——contain 会留下大片黑边。
5. 选定后按 [visual-planning.md](visual-planning.md) 第 3 节先生成一张校准图，实际查看合格后再继续。

### 选型表

| 这一段在讲 | 首选 | 备选 |
|---|---|---|
| 真人经历、门店/工厂/办公场景、人群、地点、劳作动作 | `real-biz-01` | `native-snap-01` |
| AI/智能体/系统/自动化/数据流/技术原理 | `tech-blue-01` | `clean-ui-01` |
| 行业与品类陈列、产品与服务清单、实体行业质感 | `warm-gold-01` | `real-biz-01` |
| 软件能力、功能清单、指标看板、流程步骤 | `clean-ui-01` | `tech-blue-01` |
| 需要临场感但确实没有实拍（仅 pacing/explanation） | `native-snap-01` | `real-biz-01` |

**不要用卡通插画做商务口播的默认风格。** 扁平二维插画只在内容本身是轻松科普或面向儿童时才合适；财务、经营、行业、B 端题材用它会显得不专业。

## 贯穿所有预设的硬性规则

- **精确文字一律本地排版**：金额、数字、图表、标题、标签都由 `template` 类目用 Remotion 排版，不让生成模型画字。中文与数字是当前模型最不可靠的部分。
- **真实证据用 `local_real`**：`purpose=evidence` 必须绑定真实文件，任何预设都不能拿来充当证据。
- **生成画面标「AI 生成示意」**，本地排版标「示意图」。
- **不出现真实品牌、可辨认的公众人物、平台 logo。**
- 重复出现的人物在同片内保持同一外形要点（写进 `rendering`）。

## 1. `real-biz-01` 写实商务纪实

最安全、最通用的商务口播风格。适合真人实拍片，与原始素材质感最容易接上。

- **id**: `real-biz-01`
- **medium**: 写实摄影，商业纪实/编辑摄影质感；非插画、非三维渲染
- **palette**: 真实自然色调，整体低饱和；以环境光为准——暖白日光、窗边冷灰、木色与肤色为主；不让某个品牌色统摄画面
- **rendering**: 真实材质与皮肤质感；浅景深（等效 f/2）；自然光或窗光为唯一主光方向，不做多灯影棚感；高光柔和滚降、暗部保留细节；35mm–50mm 视角无畸变；轻微胶片颗粒
- **composition**: 竖幅时主体置于画面中上部，视线方向留出空气；背景交代行业环境而非纯色背景；下方约三分之一为平缓低对比区域供字幕；横幅时主体偏左或偏右，留出文字侧
- **avoid**: 矢量插画、三维塑料质感、霓虹与赛博光效、HDR 过锐、摆拍露齿假笑、可读文字与商标、过度磨皮的塑料皮肤

**prompt 附加词**：`写实摄影质感，自然光，浅景深，真实材质与皮肤，低饱和自然色调，35mm 视角，非插画非三维渲染`

## 2. `tech-blue-01` 深色科技蓝

AI/技术概念的标准视觉。暗场 + 电光蓝辉光，科技感最强。

- **id**: `tech-blue-01`
- **medium**: 高保真三维科技概念视觉
- **palette**: 深蓝黑底（#0A1220–#101B33）；主光电光蓝 #2E9BFF；青色 #56E1FF 作边缘光；白色只用于最高光；不使用暖色
- **rendering**: 玻璃拟态与半透明面板；金属与亚克力反射；体积光与辉光溢出；细网格与粒子；发光描边；主体由自身发光，置于暗场中
- **composition**: 竖幅时发光主体居中偏上，周围环绕半透明数据面板或节点连线；四周自然暗角；底部保持低亮度以便承字幕。横幅时主体居中，两侧对称铺陈面板
- **avoid**: 写实人脸、暖色与金色、扁平插画、卡通、真实品牌标识、任何可读文字或数字

**prompt 附加词**：`深蓝黑背景，电光蓝与青色辉光，玻璃拟态半透明面板，体积光，细网格与粒子，暗角，无文字`

## 3. `warm-gold-01` 金棕奢华商业

实体行业与产品陈列的质感风格。金色三维物件 + 写实虚化底图。

- **id**: `warm-gold-01`
- **medium**: 高端商业静物视觉；写实底图 + 金色三维物件
- **palette**: 深棕 #2B1B10 至暖棕 #4A2F1C 的暗底；香槟金 #D9B472 与 #F0D9A8 为主材；暖白高光；不使用冷色
- **rendering**: 金色拉丝与抛光金属质感；玻璃通透感；写实背景大光圈虚化；柔和方向光与暖色反射；物件有真实重量感与落地投影
- **composition**: 竖幅时上方留出标题区，中部为等距物件阵列（每件独立、留空隙），底部为低对比暖色过渡区供字幕。横幅时物件横向排列
- **avoid**: 冷色与霓虹、赛博光效、扁平插画、可读文字与数字（金额与标签一律本地排版）、真实品牌、杂物堆叠

**prompt 附加词**：`深棕暖色背景，香槟金金属与玻璃质感，柔和方向光，大光圈虚化，物件等距陈列，无文字`

## 4. `clean-ui-01` 明亮产品界面

软件能力与数据的载体。浅色界面感，阅读负担低。

- **id**: `clean-ui-01`
- **medium**: 现代 SaaS 产品界面视觉，半写实界面感
- **palette**: 白 #FFFFFF 与浅灰 #F4F6FA 为底；品牌蓝 #2F6BFF 与淡紫 #7C6BFF 渐变作强调；深灰 #1F2937 作层级块面（示意为无色块，不写字）
- **rendering**: 卡片式布局，1px 浅描边，柔和多层投影；大圆角；细线图标；数据以抽象图形表达；界面元素有层级与浮起感
- **composition**: 竖幅时上方为顶栏示意，中部为主卡片与图表区，元素按规则栅格水平对齐，底部渐隐。横幅时左右分栏
- **avoid**: 真实品牌界面、可读文字与数字（一律本地排版）、写实人脸、照片元素、暗色科技辉光

**prompt 附加词**：`浅色界面感，白与浅灰底，蓝色与淡紫渐变强调，卡片式布局，柔和投影，抽象图表，无文字`

## 5. `native-snap-01` 原生随拍（受限）

临场感最强，但也最容易被误当成真实证据。**只能用于 `purpose=explanation` 或 `pacing`。**

- **id**: `native-snap-01`
- **medium**: 手机随拍/UGC 质感的日常记录
- **palette**: 现场色，允许混合色温与偏色，不做统一调色
- **rendering**: 手机广角；构图略显随意、可有轻微倾斜；允许高光溢出与轻微噪点；非专业布光；环境允许杂乱
- **composition**: 随手取景，主体不一定居中，允许前景遮挡
- **avoid**: 影棚布光、商业修图、插画感、精致摆拍、可读文字

**prompt 附加词**：`手机随拍质感，现场混合光，构图随意，轻微噪点，非专业布光，无文字`

**限制**：因为不是真实来源，它**不得**用于 `purpose=evidence`（校验脚本会拒绝），必须带「AI 生成示意」标签，也不要用在需要事实支撑的结论句上。

## 与本地排版的分工

| 画面内容 | 来源 |
|---|---|
| 场景、人物、行业环境、物品、概念氛围 | 上面任一预设的 `generated` |
| 金额、数字、对比、流程、清单、图表、箭头 | `template` 本地排版 |
| 截图、录屏、现场照片、票据 | `local_real`（并核对授权） |

同事/历史素材库里带大量精确中文的海报，属于**设计产物**而非生成模型的输出。需要那种版式时用 `template` 排版，不要指望生成模型把中文写对。
