# 从文案或主题制作分镜视频

先根据用户的用途和目标时长整理分镜，不套口播的删重拍/气口步骤。每个镜头给出信息目的、画面描述、时长、可选旁白/字幕、图片或视频类型；按内容选择已有图片或视频素材。

逐镜头登记已有素材的来源与本地路径，核对与脚本的关系；素材缺项明确列出，不调用已移除的空镜生成与插入流程。

整体制作将镜头统一尺寸/帧率，使用 Remotion 或当前已有后端拼装。字幕和文字使用 [fonts.md](fonts.md)；将需要准确的文字/图表放在模板中，不把乱码生成图直接交付。若用户需要配音而没有音频/可用配音服务，先完成视觉和脚本，再明确缺少的配音步骤。

渲染后核查所有镜头衔接、文字、音频及输出规格，按主 Skill 的最低交付要求同时输出 MP4 和完整剪映草稿。按 [剪映工程导出](jianying-export.md) 的分层输入方式，把同一时间轴的镜头、配音/BGM 和文字放入独立轨道，保留原渲染工程、资产及逐项质检。主流程的脚本和镜头计划是当前任务产物，不因新主题自动安装新的子 Skill。
