# 从文案或主题制作分镜视频

先根据用户的用途和目标时长整理分镜，不套口播的删重拍/气口步骤。每个镜头给出信息目的、画面描述、时长、可选旁白/字幕、图片或视频类型；把仅靠一张图片即可说明的概念留给图片生成，把动作与过程交给视频生成。

整片画面策划与统一画风遵循 [visual-planning.md](visual-planning.md)，选型从 [visual-styles.md](visual-styles.md) 的预设里挑一套（一条片子只用一套，画幅跟随成片），没有原声时用稳定脚本句 ID 作为 `source_word_ids`，不得伪造 ASR 词 ID。生成调用和下载遵循 [generated-media.md](generated-media.md)。纯素材任务没有 final 时间轴时，给一条临时素材时间轴以复用清单校验；它仅用于取回镜头，不构成整片。`adaptive` 不能保证画幅，下载后核对后再安排构图。

整体制作将镜头统一尺寸/帧率，使用 Remotion 或当前已有后端拼装。字幕和文字使用 [fonts.md](fonts.md)；将需要准确的文字/图表放在模板中，不把乱码生成图直接交付。若用户需要配音而没有音频/可用配音服务，先完成视觉和脚本，再明确缺少的配音步骤；百炼生视频的伴随声音不能当作指定旁白自动通过。

渲染后核查所有镜头衔接、文字、音频及输出规格，交付工程、资产和逐项质检。主流程的脚本和生成计划是当前任务产物，不因新主题自动安装新的子 Skill。
