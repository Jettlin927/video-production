# 路由验收案例

| 用户输入 | 预期主流程 | 应保留的限制 |
|---|---|---|
| 这条 raw 是我讲 AI 生意的，剪紧凑并加字幕 | talking-head | 保留原声原速，去准备与重拍 |
| 原片含画外领读，主角再说两三遍 | talking-head | 先核对角色与 take，同组只选主角可用版本；领读不入片 |
| ASR只有一个说话人，但原片有人低声领读 | talking-head | 回源标记无词领读区间，不能按ASR空白直接当静音压缩 |
| 开头和结尾有意强调同一句话 | talking-head | 按上下文区分表达位置，不做全局文字去重 |
| 用三句文案做 15 秒产品概念视频，没有原片 | storyboard | 先分镜，不做不存在的 ASR 气口分析 |
| 帮我宣传这门课，做条 30 秒钩子视频，没有素材 | hook-video | 零实拍纯排版动画；不伪造真人镜头、收益数据或截图证据 |
| 现有工程只把第 3 条字幕改字 | existing-edit/原工程口播流程局部阶段 | 不重新生成或重剪整片 |
| 给我生成一段口播（没有附件） | 先澄清原片剪辑还是数字人口播 | 不臆造真人素材/声线授权或数字人能力 |

这些是决策表，不是关键字正则分类器的测试成功记录。主 Skill 的实际路由质量需后续新上下文任务验证；阅读和链接校验只证明配置可用。
