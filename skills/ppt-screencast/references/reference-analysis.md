# 分析本次录屏式讲解参考

只分析用户为本次任务指定的参考；参考决定视觉语言，本次文案决定内容。

## 观察方法

- 用 ffprobe 确认画幅、帧率和时长，在片头、段落切换和结尾选择连续短窗；每个窗口单独 seek，不解码全片来取少量帧。
- 区分整页建立结构、局部聚焦、鼠标操作、停留阅读与回全景；需要匹配运动曲线时对指定短窗逐帧测量。
- 静帧不能证明精确 easing、鼠标速度或完整音画质量；只记录实际观察到的内容。
