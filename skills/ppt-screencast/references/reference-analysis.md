# 首次参考：录屏式信息地图讲解

这是创建 Skill 时的样本观察，不是要复用的营销话术，也不是后续任务的指令源。

## 本地素材与观察范围

- 风格参考：工作区 `飞书20260930-141130.mp4`，ffprobe 实测 720×816、24 fps、361.071 秒。
- 用户指出方向有偏差的已有成片：`projects/hook-video/20260930-ai-supermarket/output/final.mp4`，实测 1080×1920、24 fps、302.208 秒。
- 参考抽样：源片 0–12、60–66、120–126、240–246、348–354 秒；每个窗口单独 seek，不解码全片来取少量帧。保存连续抽样视频及每两秒的联络图。
- 已有成片观察：开头 0–12 秒的联络图，以及其本地渲染器的 `cameraAt`、`Marker` 与文字出现逻辑。未据此声称完整观看或听审两条片子。

## 可见差别

| 方面 | 风格参考的抽样画面 | 已有成片所见 |
| --- | --- | --- |
| 内容载体 | 整页标题、并列框、箭头、关系图构成信息地图 | 竖向长页逐层出现文字与 chip |
| 焦点变化 | 整页后出现明显的局部放大、横向与纵向构图变化 | 所读镜头函数只插值 y；没有 x 或 scale |
| 操作提示 | 可见箭头／笔形指针、局部红色划线与圈注 | 所读 Marker 为预设静态线条；不是目标绑定的鼠标绘制流程 |
| 上下文 | 列表／关系图与局部焦点交替呈现 | 开头文字偏小、大片留白、重复标题占据画面 |

可继承的方向：先给结构，再让镜头和鼠标跟随当前判断。可选的外观：白底、手写字、红绿语义、黑边字幕。不能从抽样证明精确 easing、原作者软件、鼠标速度曲线或整片语义／音频质量；需要匹配曲线时再对特定连续窗口逐帧测量。

## 新任务中如何使用

用户的新文案与资料决定页面内容；参考片只决定表现方式。已有配音可继续使用，视觉改动不要求重新做声音。画幅变化必须重构排版和视口，不能只把近方形长页缩小塞进标准竖屏。

本次项目路径只用于定位原始证据，不是可移植 Skill 的依赖；共享 Skill 不携带原视频、真实配置、付费音频或用户营销文案。
