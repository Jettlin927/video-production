# 两行滚动字幕与字体参考

用户希望字幕随原声推进：长句按语义与实际字宽拆成短语行；第一行在下方出现，开始说下一行时，原下行上移、新行在下方出现。继续讲第三行时，最旧上行退出，保留最近两行。示例中的“20 字”不是固定阈值；金额、专名、否定与完整短语优先保持完整，再根据正文/重点字体实测宽度。

## 三个时间

- speech_start/end：词级原声在 final 时间轴的位置，用来判断何时读到。
- 行的 current 区间：本行开始说起，直到下一行开始或语义组结束。
- display_end：本行移到上方后可继续保留，直到再下一行进入；最后一行默认尾部保留约 120ms，但不越过下一语义组或成片尾部。

重点从对应完整短语的第一个词开始强调，随该行继续显示；移到上行后减弱视觉权重，行退出时重点一并退出。按短语选择白色粗体、下划线或底框；不要整句从一开始全部高亮。正文与重点允许不同字体族，分别加载真实字体文件和字重。

动画默认约 160ms，在 25fps 下为 4 帧；短行将动画限制在本行存在区间。上移、淡入和退出使用同一 final 帧时钟，不拖长音频。语义组结束或长停顿时清空旧句；换段不把上一观点挂在新句上方。

## 编译与渲染

`rolling-editorial.json`：保留 revision/fps/duration_frames，`groups` 每组含唯一 id、takeaway、lines。每行包含 `word_keys`（instance_id:id）和可选 emphasis（word_keys、role、reason、marker=underline/box/none）。沿用 `caption_pages.py` 的词覆盖、完整短语和过期版本检查。

按 [semantic-pacing.md](semantic-pacing.md) 先标气口、固定候选时间轴，再规划并编译字幕，之后切媒体。一次句内去空档会把媒体段拆成多个 instance，但字幕语义组继续沿用；改气口时按稳定词 ID 更新 word_keys 和时码，复用已有重点理由。

```powershell
python scripts/rolling_captions.py --words words.final.json --editorial rolling-editorial.json --out captions.rolling.json
```

把 `assets/remotion/CaptionLayer.tsx` 和 `RollingCaptionLayer.tsx` 一起复制至工程；后者调用前者的字体加载函数。将 compiled.lines、字体清单及正文/重点字体族传给 RollingCaptionLayer。编译器同时生成两行 SRT：包含上一行和当前行的可见文字，动画、重点样式以 MP4/工程为准。

实帧验证行切换前一帧、触发帧、动画中间、动画结束和组间清空，覆盖三行以上长句、金额/英文、重点较晚出现、最后一句。测量实际正文和重点字体宽度，检查上移后的上行不遮挡嘴部或其他内容。词在数据中只映射一次；字幕保留导致的跨 cue 重复显示是预期行为。

## 用户提供什么文件

- PNG/JPG 截图：用于学习字形、粗细、描边、阴影、色彩和重点符号。优先提供原分辨率、有背景的完整画面，正文与重点分别举例；单张静图不能还原动画时序。
- MP4/MOV 样片：若希望参考具体上移动效，提供约 3–10 秒、包含一次完整换行和重点出现的片段。
- TTF/OTF（或 WOFF2）：实际字体文件，最好同时附字体名称、字重、授权来源。PNG 是样式参考，无法当作覆盖任意新文案的完整字体。
- 透明 PNG/SVG：适合手绘箭头、下划线、圈画等装饰元素，需保留透明背景。收到后按实际尺寸适配，不将它误当字体文件。

在用户提供素材之前，用现有有许可字体验证行为；接收后再匹配视觉风格，不声称已经复刻尚未提供的样式。
