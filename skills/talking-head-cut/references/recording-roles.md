# 先分角色，再选同一句的可用版本

选段前读取本页。拍摄方式、真人角色与 ASR speaker_id 是三件事：画面只有一个人，可能仍有画外领读；ASR 只返回一个人，也可能只是没识别出较小的领读声。相同字幕不能证明是同一个人重拍。

## 三类素材的处理

| 情况 | 确认方法 | 选段方式 |
|---|---|---|
| 主角独自讲完全程 | 核对原声与连续嘴型，检查是否有重拍、拍摄交流或画外提示 | 标 `solo`；正常正文保留，重拍归组后选一次，有意强调可保留 |
| 有领读，但 ASR 漏掉领读声音 | 在复述前后、较长无词区间回看回听；一个 speaker 不能排除领读 | 标 `guided_inaudible`；主角版本正常归组，漏识别的领读/交流以源时间区间排除 |
| ASR 识别出领读和复述 | 用相邻的同义句对照声音、嘴型和上下文，确认哪些是领读、哪些是主角 | 标 `guided_audible`；领读只作理解文案的参考，主角复述才进入可选素材 |

同一原片可混用这些拍法，记 `mixed` 并逐段判断。所有情况都可能出现主角复述两三遍，不能假设“奇数领读、偶数主角”或固定取最后一遍。人数参数只影响识别参考，不解决真人身份。

## 默认走轻量核对

沿用现有转写、内容选择、气口、字幕和交付链路。角色核对只做一次：先用少量有代表性的连续领读/复述样本确认 speaker 与真人角色的对应关系，写入 `speaker_roles`，全片复用；不要求对每句话重写角色和证据。纯口播同样先确认身份，再复用一个主角映射。

只有角色混淆、ASR句界串人、主角多次重拍需要特别防止混剪、或无词区间有领读声音时，才追加对应范围的 `spans` / `excluded_audio`。正常的重拍比较与原有选段一并完成，不另外逐句做一次完整审片。不要全片重转ASR、反复读完整词稿、每个候选单独发工具调用，或为核对身份重渲染多版成片。需要的样本一次批量取回，角色结果未变就复用。

新增角色判断以少量分钟为目标，不承诺固定耗时。若少量代表样本已显示说话人编号不稳定，升级检查受影响区间；仍无法确认时及时报告具体疑点，先保留候选计划，不能悄悄扩展成数十分钟的全文标注或靠猜测通过。

## 1. 角色核对与证据

复用带 speaker_id 的原转写，运行 `index`。现在同时输出 `words.tsv`、`utterances.tsv`、`recording-review.json` 和原有 `selection.json`。词表前五列保持原顺序，后面追加原/修正 speaker、utterance 和 channel；句表也保留说话人。ASR 句界只是候选，不是拍摄 take 边界。

先查看开头、中段、结尾及明显重复的相邻片段，至少包含连续发音和停止发音的上下文。声音远近、音色、领夹麦位置只作辅助，必须结合实际原声、连续嘴型与拍摄交流判断；单张闭嘴截图可能只是发音间隙，不能单独证明领读。

角色为 `performer`（主角正式表达）、`prompt`（画外领读）、`production`（拍摄交流）、`unknown`。角色可以跨 ASR speaker 编号，也可能同编号里混了两个人。保留原模型标签，在角色表中按真实词范围修正归属；混合句先拆范围再标角色，不能整段按编号删除。

证据写清原片区间、查看/听审方法和观察，例如“原片28.8–30.3秒连续画面中主角未发音，随后30.6–31.9秒主角复述；原声已核对”。不能用“文本更顺”“画面只有一个人”或“ASR很自信”替代证据。没有可用听审/连续画面证据时，保留 unknown；可以继续整理候选，不把未确认范围交给最终剪切。

## 2. 同一句的领读和多次复述归组

以语义单元分组，例如“一个观点及其必要条件”，不是按标点或固定字数分组。一个组可能是：领读一次 → 主角第一次口误 → 主角第二次卡顿 → 主角第三次完整。ASR 可能拆成多句，也可能将几次复述合成一句，需按源时间与词索引拆分。

同句主角版本在原有内容选择中一起比较。需要记录重拍组以防混剪时，才在 spans 中使用同一个 `group`、不同 `take`；一遍完整表达被 ASR 拆开时，可用多条 span 标注相同 group/take。不要为全片每个正常句子制造人工 group/take 字段。选主角完整、自然、词头尾音清楚、表情手势可用的一遍；优先保住否定、条件、数字与单位。画外领读即使更短、更流畅、识别字更正确，也不能替代主角。

每组默认只选一个 take，可在同一 take 内清理口误或无效等待。不要从领读和复述里各拿几个字拼句，也不要因为文字能接通就混用两三遍的碎片。没有完整可用版本时保留较完整一遍并列明问题/补拍建议，复杂拼修交人工处理。

不同上下文中的有意重复（如开头观点与结尾呼应）是不同表达位置，分别建组并写出作用，不做全局文字去重。用户要求的精华提炼、原有内容取舍和重排继续在可用的主角版本中进行。

## 3. 角色表与选段契约

编辑 `recording-review.json`，保留程序生成的 `source_revision` 和 `transcript_hash`。填写 `mode`、`evidence`，完成核对后将 `status` 设为 `reviewed`。其中：

- `speaker_roles` 每个 channel/speaker 一条，填已核对角色与共同证据。未确认的编号保持 unknown；程序不会因编号大小、人数或文本相似自动赋予主角身份。
- `spans` 默认空，只填写例外，first/last 是从1开始、包含两端的源词范围，不要求覆盖整条转写。每条例外的角色覆盖对应 speaker_roles；不确定处可覆写为 unknown，防止被默认映射带入成片。
- 非 unknown 例外需证据。需要特别记录的重拍组再成对填 `group`、`take`；程序检查这些已标注组不混用多个版本。未标注的重复仍由原有内容选择与短样检查判断，程序不声称自动找到了所有重拍。
- `excluded_audio` 标记有声音但未成为 ASR 词的领读、交流或不确定区间，使用源秒数及证据。空列表表示没有发现需要单独排除的区间，不代表 ASR 空白都是静音。

常见双人领读素材的轻量结构（编号只是示例，必须先核对；保留自动生成的版本和指纹字段）：

```json
{
  "status": "reviewed",
  "mode": "guided_audible",
  "evidence": "原片连续领读/复述样本的视听核对记录",
  "speaker_roles": [
    {"channel_id": 0, "speaker_id": 0, "role": "prompt", "evidence": "源片代表区间内的画外领读依据"},
    {"channel_id": 0, "speaker_id": 1, "role": "performer", "evidence": "源片代表区间内主角发音依据"}
  ],
  "spans": [],
  "excluded_audio": []
}
```

选段仍用原有 `selection.json.ranges` 的 first/last/reason。`select` 增加必填 `--review <recording-review.json>`，其余剪辑、字幕和双交付链路保持原样。程序会拒绝：缺少/过期角色表、保留未知角色或非主角词、已标注同组混用多个 take、选段跨过已标出的无词领读音频。与选段无关的 unknown 不阻塞。

程序只校验已填写决定的一致性，不会验证证据文字是真是假，也不声称自动理解声音。角色确认和版本优劣仍是内容判断。

## 4. ASR 漏识别领读的边界

只删字幕不会删除领读声音；把长无词区间压成20ms也不等于已经去掉领读。检查保留段前后、重复句之间和段内的无词区间，发现低声领读或拍摄交流就记录 excluded_audio。

若排除区间落在选段内部，将 ranges 拆到两侧的主角原声，不能让该区间进入气口压缩。若在选段外侧，程序自动收紧最多40ms的保护余量，避免把低声提示重新带回成片。若与主角字音相交，先回源修正时码/取舍；必要时只复识别带上下文的短窗并记录偏移，不为此盲目重转全片。

## 5. 复用与验收

重复运行 index 不覆盖已编辑的 selection 或角色表。旧项目重做选段时，先在原索引目录运行 index 补出角色表，再标注并传给 select。早期逐句角色表仍可使用；转为轻量模式时填写已核对的 speaker_roles，只保留真正需要覆写的 spans，空白占位条目清掉即可，不必逐条填写。词稿变更会使旧角色表过期；保留旧证据，在新的索引目录生成新表并复核。旧成片不会自动修复。

角色表进入 selection-plan，并随同一 revision 保存在最终计划快照中。复用角色核对的原片短窗和 deliver 已有短样，检查领读/复述交界、多次重拍取舍及弱起音；有具体异常才补相应区间，不另建一套常规短样渲染流程。全片交付 MP4 与剪映工程。分别验收角色正确、领读/重拍残留、接句自然及技术规格；实际看了几段/几帧就记录几段/几帧，生成了抽帧文件不等于看过。
